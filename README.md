# Data Redundancy Removal System
### CodeAlpha Internship — Cloud Computing Task 1

## About
A cloud-based system that detects and removes duplicate data before storing it in the database using SHA-256 hashing and smart normalization.

## Features
- Duplicate detection using SHA-256 fingerprinting
- False positive prevention via normalization
- Real-time SHA-256 hash display
- Live database stats dashboard
- Dark themed professional UI

## Tech Stack
- Python + Flask
- SQLite Database
- HTML / CSS / JavaScript

## How to Run
```bash
pip install flask
python app.py
```
Visit `http://127.0.0.1:5000`
